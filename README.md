---

## 🌟 Key Features

### 🤖 Articulated 3D AI Robot Mech
- Built in **Three.js** with metallic PBR surfaces, glowing quantum reactor core, and animated scanning eye visor.
- **Dynamic Gaze & Kinematics**: Tracks mouse cursor micro-movements during idle monitoring, locks gaze towards hovered destination nodes, aims its right servo arm, and executes an energetic throwing motion.
- **Resilient Fallback**: Automatically switches to an animated 2D SVG/Canvas cybernetic HUD avatar when WebGL is unavailable or when the user toggles **Reduced Motion Mode**.

### 🚀 Ballistic Tool Throwing System
The signature interaction of the portfolio:
1. **Target Lock**: Hovering or focusing any navigation node triggers coordinate detection and robot arming.
2. **Tool Retrieval**: The robot materializes the destination's unique holographic tool in its hand.
3. **Curved Flight Arc**: Dynamic quadratic Bezier projectile flight paths computed on-the-fly from the robot's hand to the target node's DOM position.
4. **Impact Blast**: Generates dynamic canvas particle trails and an expanding shockwave burst upon arrival, decrypting and opening the destination module.

- **Framework**: Next.js 16 (App Router & Turbopack)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18.17 or later)
- npm, yarn, or pnpm

### Installation

1. Clone the repository:
```bash
git clone https://github.com/ysujith728/portfolio_website.git
cd portfolio_website
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm run start
```
